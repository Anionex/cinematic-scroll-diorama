# 滚动叙事与离线交付

## 简单、可整合的页面

沿用已有技术栈；新项目默认 Three.js + HTML/CSS/JavaScript。共享一个 WebGL 渲染器与帧循环，各章使用独立场景分组。正文使用 HTML，照片保留原片来源；不要搭建编辑器或通用插件框架。

为了复用检查脚本，封面、内容章和结尾使用 `main section.chapter`，真实照片放在 `.memory-photo img`。每章滚动进度由实际 section 位置计算；布局变化时重新读取区间，不硬写某台显示器的像素坐标。

滚动时间线决定相机、显隐和配色，回滚可还原。章节至少有完整阅读停留、模型展示和退出；退出后衔接下一章，不在 sticky 失效后的空白区等待数秒。晚景、夜景和深色结尾共用连续配色状态，不能在换章时重置为浅底。

保留原生滚动与模型直接拖动；尊重减少动态偏好，减弱镜头与环境动画，不新增教程或操作工具栏。

全屏章节、文字容器和转场遮罩不能吞掉画布的指针事件；非交互覆盖层使用 `pointer-events: none`，必要控件局部恢复。最终在有文字和照片的画面实际拖动，确认模型视角改变且松手后滚轮仍可用；仅注册事件或检查截图有变化不足以证明拖动生效。

## 单文件导出

优先复用可靠的项目构建器。使用 Vite 时，应产出单 JS chunk、合并 CSS 并内嵌脚本引用的二进制资源，例如：

```js
build: {
  assetsInlineLimit: Number.MAX_SAFE_INTEGER,
  cssCodeSplit: false,
  modulePreload: false,
  rollupOptions: { output: { inlineDynamicImports: true } },
}
```

纹理/模型使用可内嵌的导入或程序生成；字体可使用系统回退，也可嵌入已有且允许使用的字体。保留依赖版本及必要的许可证信息。开发时可以运行服务器，最终观看不需要它。

本包打包器针对**已经打成单 chunk 的静态页面**，不是 JavaScript bundler。先构建，再运行：

```sh
npm run build
python /path/to/cinematic-scroll-diorama/scripts/package_html.py dist/index.html
```

它通过 HTMLParser 内嵌 HTML 引用的脚本、样式与图片，处理内外置 CSS 的 `url()` 资源，从页面 `<title>` 自动生成文件名。CSS `@import`、`srcset`、构建目录含多份 JS 产物会明确报错；请使用干净的单 chunk 构建目录。

打包器不解析 JavaScript 依赖图，脚本内的导入与动态资源须在构建阶段打包/内嵌。它只报告“已打包”，是否独立可用仍须经过下面的离线浏览器检查，不能把打包成功当作验收通过。

**内联时保留 `type="module"` 的延迟执行语义**，或把经典脚本放在完整 DOM 后。不要把构建产物中的 head 模块直接改成即时执行的普通脚本，否则 canvas/章节尚未解析，会出现空对象错误。

所有必需资源完成内嵌后，将产物复制到独立目录，以 `file://` 断网运行。检查实际加载，不能只搜索有没有 CDN URL。

## 一次有针对性的验收

已有浏览器工具优先；若使用本包脚本，复用可用的 Python + Playwright 运行环境。没有依赖时由 agent 在项目隔离环境中准备，不让最终观看者安装；不读取浏览器个人配置。

```sh
python /path/to/cinematic-scroll-diorama/scripts/verify_offline.py dist/自动生成的文件名.html
```

脚本使用临时独立目录、断网浏览器、请求拦截、每步超时、最终进程清理；生成章节截图和结构化结果。非默认尺寸使用 `--viewport 1440x900`。默认在各章可停留区间的 35% 处截图，用 `--chapter-progress 0.5` 等选择实际阅读位置；若各章节奏不同，另用现有浏览器工具取对应帧，不能把统一进度当作阅读帧已合格。运行前完成构建，测试期间不重建同一目录。

机器检查资源、章节、照片与原生滚轮的前进/回退。**仍需人工查看截图与代表性连续帧**，确认模型质感、构图、动画方向及章节衔接。缺陷修复后只重测受影响范围，成功后不因固定轮数再重复验收。

`status: runtime_passed` 和退出码 0 只表示基础运行检查通过，`acceptance: pending` 表示整体验收尚未完成；报告的 `unverified` 列出视觉、模型结构、世界坐标、拖拽与转场等未验证项。结合页面负责人的实测证据及主代理的集成检查形成最终结论，不把脚本结果改名为整站通过。运行失败会覆盖旧报告，避免复用上次的通过状态。

若不得不跳过浏览器运行或视觉检查，清楚报告缺少的证据，不宣称离线或视觉已通过。最终面向用户只给作品文件、打开方式与必要限制；内部检查产物留在项目内。
