# 网页微缩 3D 场景制作

在制作样板和章节模型时读取。只处理相册数字展实际需要的 Three.js 程序几何、材质灯光、镜头和场景接入；问答、照片编排、交付与验收沿用 [主流程](../SKILL.md)。

## 从照片到立体模型

1. 从对应原照片提炼轮廓、长宽高比例、标志性结构与配色。保留辨识特征，不根据地点名另造无关场景，也不逐像素复刻。
2. 用真实几何搭建地形、主体与支撑。先让 3/4 斜俯视下的大形成立，再补屋檐、栏杆、轮轴等必要部件；不能把整张照片贴在平面上冒充模型。
3. 按镜头路径补全可见侧面、背面、屋顶和底部。改变轮廓、厚度、遮挡或投影的结构由几何承担，贴图只提供表面细节。
4. 大形、取景和光照成立后再加细节。复用项目几何、材质与建模函数；大量重复物体才使用实例化，不堆面数掩盖造型不足。

## 构图、材质与灯光

- 沿用整站色板与材质气质，让主体在尺寸、位置和明暗上占优，地形与配景服务主体；不要把各章做成相同方盒，也不要随意混搭渲染风格。
- 默认用能读到正面、侧面和顶部的 3/4 斜俯视；透视强弱服从主题。为正文和小幅原照片留出低干扰区域，不靠遮挡或裁切隐藏模型缺陷。
- 用基础色、粗糙度和金属度区分木、石、土与金属，避免所有表面都像高光塑料。主光建立体积，柔和补光保留暗部；接触阴影体现落地和前后层次。
- 相邻场景保持协调的光向、色温和色彩处理。控制水面透明排序与阴影偏移，不能盖住桥脚或让物体看似悬空；细节密度以实际观看距离为准。

## 几何与结构检查

- **支撑完整**：柱脚落地，桥面有合理支承，屋顶落在墙体上，车轮接地；接触阴影不能代替缺失的支架。
- **侧后面成立**：墙体、屋檐与薄板有必要厚度，滚动后不会露出空壳。屋顶斜面、接缝和端面闭合，顶点绕序与朝外法线正确。
- **表面可靠**：消除重复面、共面闪烁与无意穿模；不统一开启 `DoubleSide` 掩盖错误法线或缺面，只有真正的双面薄片才使用它。
- **沙盘边缘对齐**：河道、水面、河岸与底座使用同一空间基准，水面出入口对应底座缺口，不越界或悬空；道路与地形边缘同样对齐。

## 镜头与滚动状态

- 先确定进入、停留和退出取景，再布置场景。每段用少量有目的的推进、横移或环绕，避免穿模、突然翻转、空场和遮住主体的前景。
- 相机位置、注视点、物体姿态与光色由同一章节进度推导，跨段连续。按初始状态计算绝对变换，不在更新时累计旋转或位移；跳转、重复调用与逆向滚动都应成立。
- 部件在正确的局部轴与父子层级中运动，不脱离主体。**车辆静止时轮子不自转**；轮子随实际行进距离转动，不能把时间或镜头移动当成车辆位移。
- 环境微动保持克制，时间由页面帧循环传入；不让所有物体持续摇摆，不在各章另开动画循环或接管滚动系统。

## 逐页验证与交接证据

页面负责人（包括子代理）必须先查看带模型、原照片和文字的实际页面截图，确认主流程中的海报级标准，再据此编写并运行空间关系检查。不能只看无排版的模型预览，也不能用数值通过代替视觉判断；纯照片页检查可计算的排版边界与遮挡，无需编造 3D 测项。

- **读取最终实际数值**：在真实场景应用章节进度、动画和父级变换后，更新世界矩阵，用 `matrixWorld`、`localToWorld()` 等读取实际几何上的连接点、轮轨接触点与方向。不能用注释、预设常量、孤立副本或同一公式两边相等证明正确。
- **能计算的关系用代码验证**：按本页实际结构检查柱底与当地地形、柱顶与承重面的距离；车身长轴与轨道切线的夹角、左右车轮与各自钢轨的接触偏差；水岸与底座边界的对应关系等。地面取接触点下方的实际表面，不假设始终是 `y=0`；坡道和曲线按当地高度与方向计算。运动关系覆盖起止和关键变化位置，不只验静止一帧。
- **结果可核查**：输出对象、章节进度、实测坐标或方向、偏差、按场景尺度设定的容差与通过/失败。容差须事先合理确定，不能为让失败项通过而放宽；不可计算或未验证的项目明确列出，不计为通过。
- **同版本证据交接**：给出每页截图及进度、验证脚本与运行结果路径、对应源码或构建版本，以及已修复项和剩余问题。代码改动使证据失效时只重测受影响部分；主代理核对最终导出与证据版本一致，复查关键结构和集成行为，不重跑整套局部验收。

## 最小接入约定

沿用项目接口。并行制作新章节时，先统一一个普通场景对象即可：

| 字段 | 职责 |
| --- | --- |
| `group` | 本章根节点；统一比例与坐标，未另约定时 Y 向上，由主页面挂载。 |
| `camera` | 镜头位置和注视点等建议，由主页面应用到共享相机。 |
| `setState({ progress, time })` | 接收本章 0 到 1 的进度及秒数，更新本组姿态与镜头建议，不操作章节 DOM 或注册滚动监听。 |
| `dispose()` | 释放本组独占资源；共享资源由所有者释放，不销毁页面渲染器。 |

交接附模型边界、尺度、镜头建议和资源归属，以及上述逐页证据。只保留与本页有关的检查，不另设验收轮数。
